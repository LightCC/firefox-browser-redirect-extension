Firefox Redirect URL

Send matching web links to your selected browser instead of loading them in Firefox.

Choose a detected browser, browse for its executable, or enter an absolute path. Leave blank for the helper's default browser (normally Edge). Select only a trusted browser, not Firefox.

Browser changes apply only after you select Save settings.

Use tenant.sharepoint.com for one host or *.sharepoint.com for its subdomains. A wildcard does not include the base domain. Full URLs and paths are not supported. Lines starting with # are comments.

The local native helper and your target browser must be installed. If routing fails, the link stays in Firefox. POST forms and embedded frames are not routed.
